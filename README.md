# Site João Pessoa

Projeto React (JavaScript puro) com 3 páginas: Home, Praia e História.

## Como rodar o projeto

```bash
npm install
npm start
```

O site abrirá em `http://localhost:3000`.

## Estrutura de pastas

```
src/
  components/   -> Header e Footer
  pages/        -> Home, Praia e Historia
  styles/       -> variables.css (paleta de cores), global.css, Page.css
  App.js        -> rotas (react-router-dom)
  index.js      -> ponto de entrada
```

## Paleta de cores

Baseada na linha "Antique White" (SW 6119) da Sherwin-Williams — ver
`src/styles/variables.css` para todos os tons utilizados.
